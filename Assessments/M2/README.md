# ABC Employee Analysis

## Overview

This project analyzes the employee dataset of ABC Company using Python.

## Objectives

- Data preprocessing
- Employee distribution analysis
- Position-wise analysis
- Age group analysis
- Salary expenditure analysis
- Correlation analysis
- Data visualization

## Libraries Used

- Pandas
- NumPy
- Matplotlib
- Seaborn

## Preprocessing

The Height column contained inconsistent values. It was replaced with randomly generated values between 150 cm and 180 cm.

## Analysis

- Team-wise employee distribution
- Position-wise employee distribution
- Predominant age group
- Highest salary expenditure by team
- Highest salary expenditure by position
- Correlation between Age and Salary

## Visualizations

- Count Plot
- Bar Chart
- Scatter Plot
- Heatmap

## Conclusion

The project provides insights into workforce composition, salary distribution, and employee demographics using exploratory data analysis.
